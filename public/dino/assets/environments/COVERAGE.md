# Photoreal migration — measured coverage

Generated by `node tools/coverage.cjs`. Do not hand-edit: prose about what
is "pending" is how this migration was twice reported ahead of itself.

**painted** means a real photoreal file reached the screen in a headless run
of that page, caught either in a 2D `drawImage` or a WebGL texture upload.
Each page is measured twice: once as it opens, and once after the run has
clicked its way into play, because most of these worlds only draw on the
far side of a tap. `helper only` means the code is wired but no photograph
ever arrived, which is the state that looks finished in a diff and is not
finished in a browser.
